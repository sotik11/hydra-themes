# Hydra Themes

Custom themes for [Hydra Launcher](https://github.com/hydralauncher/hydra).

Each theme lives on its own branch:

| Theme | Branch | Version |
|---|---|---|
| Emerald Jungle | [`emerald-jungle`](https://github.com/sotik11/hydra-themes/tree/emerald-jungle) | 1.1 |

## Installing a theme

Hydra can't import a theme from a file yet, so paste the CSS instead:

1. Open the theme's branch and copy `<theme>/theme.css`.
2. In Hydra: **Settings → Appearance → Create**, name the theme, paste the CSS, save.
3. Optional: open the theme in the theme editor and upload `<theme>/achievement.wav`
   as the achievement sound.
